# Makers' marks

`qwen.svg` and `minimax.svg` are the colour icons of Lobe Icons
(`@lobehub/icons-static-svg` 1.95.1, https://github.com/lobehub/lobe-icons), MIT
licensed, Copyright (c) 2023 LobeHub (the licence is in `LICENSE-lobe-icons.txt`),
with the fixed `width`, `height` and `style` attributes removed so the cockpit sizes
them. `alephalpha.svg` is the same set's Aleph Alpha icon (`icons/alephalpha.svg`, which
the set ships in one colour only), with the same three attributes removed. `nvidia.svg` is
the same set's colour NVIDIA icon (`icons/nvidia-color.svg`), the same three attributes
removed. The marks themselves belong to their owners (Qwen to Alibaba Cloud, MiniMax to
MiniMax, Aleph Alpha to Aleph Alpha, NVIDIA to NVIDIA); the cockpit shows them only to say
which model a lane runs.

`ornith.svg` is no one's mark: a plain red ring drawn for this repo, since Lobe Icons has no
Ornith icon (checked in 1.97.0, 2026-10-21) and the cockpit shows no logo it has no licence to
show. It stands for the Ornith 1.5 122B lane only.
